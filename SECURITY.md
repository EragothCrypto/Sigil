# Security Policy

## Supported Versions

Security fixes are provided for the current Chrome Web Store release and the current production web/API deployment. Older extension packages and self-hosted snapshots are not supported.

## Reporting a Vulnerability

Please report suspected vulnerabilities privately to `info@s3ntrylabs.com` with the subject `Sigil security report`.

Include the affected component and version, reproduction steps, potential impact, and any proof of concept that does not access other users' data. Do not publish the issue or perform destructive testing against production users. We will acknowledge actionable reports, coordinate remediation, and communicate when disclosure is appropriate. This policy does not promise a bug bounty or compensation.

## Scope

Reports concerning the Sigil web app, public API, Chrome extension, or official deployment are in scope. Third-party wallets, blockchains, model providers, explorers, RPC operators, and browser vulnerabilities should be reported to their respective operators unless Sigil's integration causes the issue.
