# Sigil Security Console: Approved Design

Kevin approved the targeted redesign on 2026-10-11, including coherent task-oriented navigation, progressive disclosure, honest example/coverage states and frontend-only release safety.

## Product Direction

Preserve the Sigil name, logo and existing components. Use opaque neutral graphite surfaces, readable body typography, restrained brand accents and semantic warning/finding colors. Remove decorative gradients, orbs and marketing composition from priority routes. No new dependency or replacement design system.

The entry page starts with checking a transaction/contract and an equally discoverable wallet-permission entry. EVM and Solana remain one product; networks are choices inside tasks, not competing brands. Main navigation uses named tasks, with secondary tools in an accessible disclosure rather than ten icon-only links.

Results present decision and next action, then explanations, then expandable full evidence. Scores remain available but are not the primary recommendation. Synthetic Solana examples remain explicitly labeled before the result and inside account evidence. Complete-for-supported-scope, partial, unavailable and unsupported coverage remain distinct and never imply wallet safety.

## Boundaries

Only frontend presentation, navigation and truthful copy may change. Preserve fetching, report parsing, evaluator logic, API semantics, risk thresholds, cancellation/context protections, wallet execution boundaries and privacy notices. Do not modify production configuration, database schema, dependencies or providers. Commit/push and jury Preview only after verification; no production promotion.

## Acceptance

Review actual before/after desktop 1440px and mobile 390px screenshots for home, Solana review/negative/partial/unavailable, and EVM reports. Check keyboard navigation, evidence disclosure, input/error/loading states, overflow and contrast. Run baseline/security tests, typecheck and build. Verify the deployed candidate. Report every one of the 20 supplied anti-patterns with scoped evidence; do not claim secondary routes fully redesigned or accessibility compliance.
