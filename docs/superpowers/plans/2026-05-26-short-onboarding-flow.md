# Short Onboarding Flow Plan

1. Add a failing onboarding regression test.
2. Add `/onboarding` to the app router and navigation.
3. Build the onboarding page with five compact lessons and action links.
4. Add a first-run homepage prompt using `sigil:onboarding-complete`.
5. Mark the roadmap item complete.
6. Run focused test, typecheck, build, and local route smoke checks.
